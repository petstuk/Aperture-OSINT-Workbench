# Aperture v4.2.3

A way to send ideas and questions to GitHub Discussions without leaving the workbench.

## Features

- **Feedback from Settings** — `Settings → Feedback` opens the public [Discussions](https://github.com/petstuk/Aperture-OSINT-Workbench/discussions/2) thread for ideas and questions, or a new GitHub issue for bugs (version prefilled). Aperture does not send reports; GitHub only sees what you post.
- **Overview prompt** — a one-time banner on Triage overview asks for feedback. Share or dismiss; the choice stays in local storage.
- **Command palette** — `Send feedback` opens the same Discussions thread.

## Notes

No change to permissions or the local-only model.

## Package

```bash
./scripts/package.sh
# → aperture-osint-v4.2.3.zip
```
